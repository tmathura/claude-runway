# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a problem

Do not open a public issue for a security problem. Report it privately with GitHub private
vulnerability reporting: open the **Security** tab of this repo and click **Report a
vulnerability**, or go to
<https://github.com/tmathura/claude-runway/security/advisories/new>.

Give the mod version. `claude plugin list` shows it for `runway@tmathura-runway`. Give the Claude
Code version. `claude --version` shows it. Say how to see the problem. Do not put tokens, passwords
or other secrets in the report.

A problem in Claude Code itself, not in this mod, goes to Anthropic, as its
[security policy](https://github.com/anthropics/claude-code/security/policy) says.
